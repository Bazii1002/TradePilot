TradePilot Desktop Alpha 0.10.0

1. Ordner nach C:\TradePilot\TradePilotDesktop kopieren.
2. Bestehende .env und stock_universe.json aus C:\etoro-bot in diesen Ordner kopieren.
3. pip install -r requirements.txt
4. python main.py

REAL Trading benötigt in .env weiterhin REAL_TRADING_CONFIRMATION=YES.
Die App speichert Bot-Einstellungen in tradepilot_app_config.json.
