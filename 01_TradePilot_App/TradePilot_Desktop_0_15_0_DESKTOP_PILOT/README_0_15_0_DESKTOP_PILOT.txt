INSTALLATION
1. Ordner an einen dauerhaften Ort entpacken, empfohlen:
   C:\TradePilot\01_TradePilot_App\TradePilot_Desktop_0_15_0_DESKTOP_PILOT
2. 00_INSTALL_TRADEPILOT_DESKTOP.bat doppelklicken.
3. Danach TradePilot ueber das Desktop-Icon starten.

WICHTIG
- C:\TradePilot\.env bleibt lokal und wird nicht mitgeliefert.
- Den installierten App-Ordner nicht verschieben, solange die Desktop-Verknuepfung verwendet wird.
- Shadow/Demo kann autonom handeln.
- Echtgeldorders erfordern weiterhin eine ausdrueckliche lokale Bestaetigung.
